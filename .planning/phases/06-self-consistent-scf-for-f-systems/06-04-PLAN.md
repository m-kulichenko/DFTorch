<objective>
Deliver the written verdict the user asked for on the 10.6 eV difference between the one-pass energy
and the settled energy, and record the electron-repulsion strength defect where a reader of the
offending line will find it.

**Plain-language orientation.** There are two ways to get an energy out of this code for the same
molecule at the same geometry.

- **One pass (`do_scf=False`).** Set the electrons up in their free-atom arrangement, solve once,
  read off the energy. Fast, and what Phase 4 validated.
- **Settled (`do_scf=True`).** Solve, see where the electrons moved to, recompute, repeat until the
  answer stops changing.

At the reference separation of 2.655 A these give -17.51 eV and -6.92 eV. That is a gap of 10.6 eV.
For scale, a typical chemical bond is worth 2-5 eV. So this is not a small correction; it is a
different answer, and the user asked for a written verdict saying which it is: real physics with a
named mechanism, or a defect with a named location.

`06-RESEARCH.md` has already done the investigation and argues, at HIGH confidence, that it is
**definitional** - the two paths are computing different quantities. This plan's job is to confirm
that finding, write it up in plain language a non-specialist can follow, hold its claims with
automated tests, and stand behind it. It is not to start from zero.

Purpose: decision D-6.03 requires the deliverable to be a **written verdict**, not a note. Decision
D-6.03 also warns that an explanation accounting only for the electron-repulsion term is incomplete,
because most of the gap sits in the band-structure term instead.

Output: a document under `docs/`, three or four tests that hold its claims, a comment recording the
electron-repulsion strength defect at the line that causes it, and a roadmap that no longer calls
this phase's shell-resolved work conditional.
</objective>

## Design decision - where the verdict lives

`06-CONTEXT.md` leaves this to the planner: its own document, or a section of the phase summary.

**Chosen: its own document, `docs/SINGLE-SHOT-VS-SELF-CONSISTENT.md`.** Three reasons:

1. It is a fact about what two code paths compute, not a fact about this phase. Anyone who reads
   either number needs it, including people who never open `.planning/`.
2. The Phase 4 pinned reference `EU_N_REFERENCE_E_TOT = -17.510444238744924` lives in the test suite
   with a docstring that does not say it belongs to the one-pass path only. The document is where
   that gets said, and where a `docs/` reader will look for it.
3. This repository already keeps its standing explanations under `docs/` -
   `F-SUPPORT-STATUS.md`, `ORBITAL-COUNT-INVENTORY.md`, `RADIAL-GRID-CONSUMERS.md`,
   `BASIS-METADATA-MAP.md`. A verdict in a phase summary would be the only one that is not.

Reversibility: **easy**. One new file.

## Design decision - what happens to Constants.py:232

Decision D-6.10 records the defect and leaves it to planning whether Phase 6 **fixes**, **guards** or
**documents** it.

**Chosen: documents it in place, and guards it with the test written in plan 06-03 task 2.** Not
fixed. Reasons:

1. Changing that line changes the electron-repulsion strength for **every** f element in **every**
   existing calculation. It is not a free tidy-up, and D-6.10 says so.
2. It was tested as a candidate cause of the runaway charge loop and disproven - substituting the f
   value changed the failure pattern but the loop still failed. Presenting it as a fix would be
   wrong, and `06-RESEARCH.md` names that specific mistake as a pitfall.
3. The human ruling of 2026-08-04 named the **shell-resolved path** as this discrepancy's remedy,
   and plans 06-02 and 06-03 build it. With the shell-resolved switch on, europium's f electrons are
   already charged at the f rate; the per-atom line is what remains for the coarser mode.

Reversibility: **easy**. A comment and a test; neither changes a number.

    level lies below every europium one - nitrogen's 2p sits at -6.84 eV while europium's shallowest
    occupied level, the 4f, sits at -1.52 eV, a mismatch of 5.31 eV. With one shared filling level
    across the molecule and no charge penalty, nitrogen fills completely at any separation. State that
    this is the textbook charge-transfer failure of non-self-consistent tight binding, and is exactly
    the reason the self-consistent method exists - not a defect in this implementation. Note that the
    parameter file parsing was independently cross-checked field by field and found correct, so this
    is not a repeat of the Phase 5 phantom-shell parsing bug.

    **What this means for the Phase 4 pinned reference.** `EU_N_REFERENCE_E_TOT =
