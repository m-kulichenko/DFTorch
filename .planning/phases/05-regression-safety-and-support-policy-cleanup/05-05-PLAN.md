<objective>
Make the library's status chatter suppressible by one documented flag, keeping today's noisy
output as the default — decision D-02 — and remove the stale `ConstantsTest` parallel table
left over from D-03.

Purpose: the user hit this directly during Phase 4 execution, piping every diagnostic command
through `grep -v` to read its own output. D-02's noisy default is deliberate and conservative:
REG-02 and REG-03 require existing behaviour to be unchanged, and a quiet default would change
what every existing caller sees. This phase makes the noise suppressible, not absent.

The work is smaller and more discriminating than the research suggested. Twenty-seven of the 112
prints are already gated behind an existing per-call `verbose` argument that defaults to off, so
they are silent today and must stay that way. Of the 85 that are unconditional, a substantial
minority are genuine failure warnings — non-convergence at maximum iterations, degenerate
Krylov vectors, a spin parameter file that would not load — and gating those would trade noise
for silent wrongness, which is the opposite of what this phase is for.

Output: a per-print classification record, a flag threaded to every status site, and the stale
constants table gone.
</objective>
