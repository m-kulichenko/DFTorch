<objective>
Settle REG-02 — "existing simple-format calculations in `experiments/1_tutorial.ipynb` remain
scientifically unchanged within documented tolerances" — with an explicit developer decision,
then build whichever regression baseline that decision selects, before the rest of Phase 5
changes any code.

Purpose: REG-02 cannot be met as literally written in this environment, and the reasons are
concrete rather than a matter of effort. The notebook's first computational cell reads
`COORD.pdb`, which is not in the repository. A later cell hardcodes a CUDA device on a machine
with no CUDA driver. No notebook-execution tooling is installed. Rather than invent a harness
and quietly redefine the requirement, this plan puts the three viable dispositions in front of
the developer with their costs, then implements the chosen one. Running first in wave 1 matters:
a regression baseline pinned after D-02 and D-04 have already edited fifteen modules is not a
baseline, it is a snapshot of the new behaviour.

Output: a decision record, and a pytest module that pins today's simple-format numbers.
</objective>

    REG-02 reads: "Existing simple-format calculations in `experiments/1_tutorial.ipynb` remain

    Nothing in the repository runs that notebook today, and three separate obstacles block
    running it, each verified rather than assumed:

    1. Cell 5, the first computational cell, sets `"FILENAME": "COORD.pdb"`. There is no
       `experiments/COORD.pdb` in the repository. The notebook is checked in referencing an

       driver. Cells 17 and 25 do guard correctly, so this is one cell, not a general problem.
    3. No notebook execution tooling is installed: nbformat, nbclient, papermill, nbval and
       ipykernel are all absent. matplotlib is absent too, so any plotting cell would fail.

    The stored outputs in the notebook's 23 output-bearing cells were produced on unknown
    hardware by unknown code, so they are not a usable baseline either.

    What matters scientifically is the substance of REG-02 — that simple-format calculations
    do not change — not the literal act of executing that file. Phase 5 is about to edit
    fifteen modules for D-02, rewrite a lookup for D-01, and touch five more for D-04. Some
    pinned baseline needs to exist before that happens.
  </context>

      <pros>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `experiments/*.xyz` and `experiments/sk_orig/**` -> `Constants` / `Structure` | Local files the user chose, read read-only. Trusted input. |
| notebook stored cell outputs -> a would-be baseline | An untrusted provenance boundary in the scientific sense: those numbers came from unknown hardware running unknown code. This plan refuses to cross it; every reference number is recomputed locally. |

No new attack surface. No network I/O, no authentication, no untrusted deserialisation, no
privilege transition. The notebook is read as JSON text for its cell sources; it is never
executed by this plan under option-a.
