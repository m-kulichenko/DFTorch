<objective>
Audit every hardcoded orbital-count assumption in the runtime package and give each one an
explicit disposition — extend it to handle 16, guard it with a named refusal, or record why it
cannot be reached — ending with a written inventory whose completeness is enforced by a test
(decision D-04, REG-04, CLN-03).

Purpose: a silently unhandled orbital-count site is the exact failure mode Phases 3 and 4 kept
catching. A well-shaped, finite, symmetric matrix with zeros where f values belong is
indistinguishable from a correct result at a glance, and it survives every finiteness and shape
assertion in the suite. The Phase 3 routing fix and the Phase 4 shell-resolved Coulomb refusal
were both instances of this. D-04 chose an audit with per-site action rather than a document,
because a document alone leaves the live sites live.

Output: a sweep script, an inventory with one row per site, refusals at the sites that need
them, and a test per guard that actually reaches it.
</objective>
